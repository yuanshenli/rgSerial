rgSerial 4 motor version
=============================================

### Description

Low level control, and python API for [Tactile-Reactive Roller Grasper](https://yuanshenli.com/tactile_reactive_roller_grasper.html) and [Roller Ring](https://github.com/Rice-RobotPI-Lab/Roller-Ring.git)
- custom serial communication protocol built on top of the protocol developed by [Rohan Agrawal](https://github.com/rohbotics?tab=repositories)
